# Tailored CV Variants

Role-targeted versions of `../cv-master.md`, one file per position. Written to be sent
as-is: each file is a complete CV, not a patch against the master.

## How these relate to the master

- **`../cv-master.md` is the source.** Every fact here comes from it (or from his own
  `indrawandev` site data where it states the same work in more detail). Never invent
  a title, employer, or number when editing a variant - change the master first, then
  propagate.
- **Living files.** Unlike `../sent/` (dated, never edited again), these are edited in
  place as the master evolves.
- **The lead title stays fixed**: `AI-Native Full-Stack Engineer · Mobile-first` in every
  header. The two accepted per-context variants are used only where they fit:
  `AI-Native Mobile Engineer · React Native Specialist` (mobile-targeted roles) and
  `AI-Native Enterprise Architect` (architecture roles).
- **Targeting** lives in the `**Target role:**` line plus the role-weighted summary,
  skills order, and bullet selection - not in a new title.
